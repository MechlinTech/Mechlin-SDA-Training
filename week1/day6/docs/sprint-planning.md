# Sprint Planning Documentation

# Week 1 Sprint Plan - Advanced Frontend & Full-Stack Foundations

## Sprint Overview

**Sprint Name:** Week 1 - Advanced Frontend & Full-Stack Foundations

**Sprint Duration:** 6 Working Days

**Team Size:** 1 Developer (Training Project)

**Sprint Goal:**

Develop a modern React-based analytics dashboard by following professional software development practices, including Git workflow, responsive frontend development, React architecture, REST API integration, technical documentation, and Agile methodologies.

---

# Sprint Objectives

By the end of the sprint, the project should demonstrate:

* Professional Git workflow
* Modern HTML5 & CSS3 practices
* Advanced JavaScript (ES6+)
* React Component Architecture
* Context API State Management
* REST API Integration
* Interactive Dashboard UI
* Technical Documentation

# Risks Encountered

## Build Script Issue

Issue:

Root project did not contain a build script.

Resolution:

Used the Vite frontend package for development and continued using the available scripts.

---

## API Integration

Issue:

Dashboard required realistic data.

Resolution:

Integrated JSONPlaceholder API and generated dashboard metrics dynamically.

---

## Git Workflow

Issue:

Managing feature branches and merge conflicts.

Resolution:

Practiced branching strategy, merges, conflict resolution, and pull request workflow.
