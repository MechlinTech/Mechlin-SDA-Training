# 1. Introduction (2 Minutes)

Good morning everyone.

My name is **Prateek Panjwani**, and today I am presenting my final capstone project developed during the Mechlin SDA Advanced Training Program.

The project is called **AI Productivity Platform**.

Its primary goal is to help users manage daily work efficiently using Artificial Intelligence.

The application combines:

- React Frontend
- Node.js Backend
- MongoDB Database
- Google Gemini AI
- React Native Mobile Application
- Docker
- Kubernetes
- GitHub Actions

---

# 2. Problem Statement (1 Minute)

Many productivity applications only manage tasks.

They do not help users:

- prioritize work
- receive AI recommendations
- monitor productivity
- access the platform from both web and mobile

This project addresses those challenges by integrating AI with a productivity management system.

# 4. System Architecture (2 Minutes)

The application consists of five major modules.

### Frontend

React.js

Responsible for:

- User Interface
- Dashboard
- Analytics
- Task Management

---

### Backend

Node.js + Express

Responsible for:

- REST APIs
- Authentication
- Business Logic
- Database Communication

---

### Database

MongoDB

Stores:

- Users
- Tasks
- Analytics
- Productivity Data

---

### AI Module

Google Gemini API

Provides:

- AI Chat
- Productivity Suggestions
- Task Assistance

---

### Mobile Application

React Native

Allows users to access the platform on Android devices.
