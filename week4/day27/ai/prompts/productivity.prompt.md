# Productivity Prompt Templates

This document contains reusable prompt templates for the AI Productivity application.

---

# 1. Daily Planner

## Prompt

Create a productivity plan for today.

Include:

- High priority tasks
- Medium priority tasks
- Low priority tasks
- Suggested breaks
- Estimated completion time
- End of day review

# 4. Time Management

## Prompt

- Include break reminders
- Focus on deep work
- Group similar tasks together
- Estimate completion time

```
{{TASKS}}
```

- Be concise
